# LittleFootCraft SKU Guide

## Format

CATEGORY-YYYYMMDD-SEQUENCE

Example:

BR-20260326-0001

BR = category prefix 20260326 = creation date (YYYYMMDD) 0001 = item number
created on that date

---

## Category Prefixes

BR = Brooches NC = Necklaces BG = Bags PT = Paintings PC = Postcards

---

## Rules

- Always use uppercase prefixes.
- Always use the creation date, not the publish date.
- Always use 4 digits for the sequence number.
- Never reuse a SKU after an item is sold or deleted.
- Variants, if needed in the future, should be appended:

BR-20260326-0001 BR-20260326-0001
